# PracticeAngularNexus

Proyecto educativo SPA en Angular para Nexus: integra una librería universitaria, servicios de cafetería y reserva de espacios de coworking en una sola experiencia.

## Cómo ponerlo en marcha

1. Instala dependencias:

```bash
npm install
```

2. Arranca el entorno de desarrollo:

```bash
npm start
```

3. Abre la aplicación en:

```bash
http://localhost:4200/
```
